# Tools

Web tools built by the community for working with Nano. For libraries and SDKs in various languages, see the <a href="https://hub.nano.org/developer-tools" target="_blank">Nano Hub developer tools directory</a>.

### Keys & Blocks

| Tool                                                                          | Description                                                                                                                                 |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| <a href="https://joohansson.github.io/keytools/" target="_blank">KeyTools</a> | Unit conversion, seed and key derivation, block creation and signing, work generation, QR codes and more. Can be downloaded and run offline |

### Explorers

| Tool                                                                   | Description                                                     |
| ---------------------------------------------------------------------- | --------------------------------------------------------------- |
| <a href="https://blocklattice.io/" target="_blank">Blocklattice</a>    | Account and block explorer with representative and network data |
| <a href="https://nanexplorer.com/nano" target="_blank">Nanexplorer</a> | Account and block explorer                                      |

### Network Monitoring

| Tool                                                               | Description                                             |
| ------------------------------------------------------------------ | ------------------------------------------------------- |
| <a href="https://nanoticker.org/" target="_blank">NanoTicker</a>   | Node versions, vote weight and decentralization metrics |
| <a href="https://nanocharts.info/" target="_blank">Nano Charts</a> | Representative weight and decentralization statistics   |
| <a href="https://nanospeed.info/" target="_blank">Nanospeed</a>    | Live confirmation time measurements                     |

### RPC Access

| Tool                                                                      | Description                          |
| ------------------------------------------------------------------------- | ------------------------------------ |
| <a href="https://rpc.nano.to/" target="_blank">Nano.to RPC</a>            | Hosted node RPC with free test funds |
| <a href="https://nanswap.com/nodes" target="_blank">Nanswap Nodes API</a> | Hosted node RPC                      |

### Test Funds
